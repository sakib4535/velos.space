# Velos Production Refactor Package

This package contains the original working source preserved before modular refactoring.

Structure prepared for production separation:
- css: theme/layout/component styles
- js/pdf: PDF handling
- js/vision: MediaPipe hand tracking and gestures
- js/canvas: drawing and laser engines
- js/camera: camera management
- js/ui: interface modules
- js/utils: helpers

Design and algorithm should remain unchanged during migration.
